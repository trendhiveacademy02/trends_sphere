01. THE ARCHITECTURE

A Remote Access Trojan (RAT) is a malware program that includes a back door for administrative control over the target computer. In the context of mobile security, Android RATs represent a significant threat vector due to the personal nature of the devices.

Defense requires understanding. By studying the command and control (C2) flows, data exfiltration methods, and permission abuse logic, security professionals can build robust detection rules (YARA, Snort) and hardening policies.
